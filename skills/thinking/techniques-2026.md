# Five Thinking Techniques for 2026

Five chains you can paste into claude.ai or ChatGPT. Each one is three prompts. Run them in order in the same chat and never start a new conversation between steps, because each prompt works on the answer before it.

Replace anything in brackets with your own.

## Fail

Use it when a plan feels safe and you want to find the slow, reasonable path to failure that is already underway.

```
Here is my project: [paste]. Write the sequence of decisions that would guarantee it fails within a year, where every decision looks smart on the day it's made. Number them.
```

```
Which of these have I already made? Be specific.
```

```
For the ones I've made, what's the cheapest way to reverse each?
```

## Taste

Use it when you know what good looks like to you but cannot say why, or your current work feels off and you cannot name the problem.

```
Here are ten things in my field I love: [list]. Ten I can't stand: [list]. Write the rules I follow without knowing I follow them, as rules, not observations.
```

```
Here is what I'm building now: [paste or point at the folder]. Where am I breaking my own rules?
```

```
Which rule, if I followed it here, changes the most?
```

## True

Use it before you commit time or money, to find the one assumption the whole plan quietly depends on.

```
My plan: [paste]. List everything that would have to be true for this to work, ranked by how unlikely each one is.
```

```
Which one can I check this week, and how, in one step?
```

```
If the most unlikely one is false, what's the plan?
```

## Flip

Use it right after any answer that sounds convincing, to find out whether it is right or just well argued.

```
Argue the opposite exactly as hard as you argued that.
```

```
Which of the two arguments did you have to stretch more to make, and where?
```

```
What evidence would settle it?
```

## Bio

Use it when how you describe yourself and how you spend your time may have drifted apart.

```
Here are my last thirty days: [calendar, git log, notes]. Write the one-line bio of the person who lived this month, from the evidence only, not from how I describe myself.
```

```
Write the same line for a year from now if nothing changes.
```

```
Which single week, changed, moves the second line the most?
```
