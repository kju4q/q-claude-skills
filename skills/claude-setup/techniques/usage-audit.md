# Usage Audit

## What this technique does
Makes Claude critique how the user has been using Claude. It surfaces the patterns in the user's own behavior that they cannot see from inside the relationship. The first run usually says something uncomfortable and true.

## When to use
- Weekly, as part of a review ritual
- When the user suspects they are over-relying on Claude for the wrong things
- When the user wants to improve the quality of how they work with Claude, not just what they ask

## How to apply

Run this on a chat or project that has real context about the user. The audit needs material to work from.

Ask Claude to audit the relationship specifically:
- Where is the user using Claude well?
- Where are they leaning on it for things they should figure out themselves?
- What pattern in how they ask for things do they probably not see?
- What is the unhealthy pattern in the relationship?

Require real examples from the conversations, not generic observations. Allow it to be uncomfortable.

The output is only valuable if the user acts on it. Pick the one observation that hit hardest and change something next week.

## Gotchas
- Run it on a chat with real context. An empty chat produces empty audits
- Generic answers mean the audit failed. Demand real examples from the actual conversations
- Reading the audit is not the technique. Acting on one observation is
- The first run is usually the sharpest. Do not flinch from it

## Trigger prompt
"Audit how i've been using you. Where am i using you well? Where am i leaning on you for things i should figure out myself? What pattern in how i ask for things do i probably not see? What's the unhealthy pattern in our relationship? Cite real examples from our conversations. Be uncomfortable if you need to."
