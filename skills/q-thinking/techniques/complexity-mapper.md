# Complexity Mapper

## What this technique does
Maps all the moving parts of a problem, how they connect to each other, which ones drive which others, and which single lever if pulled would create the most change across the whole system. Most people try to solve everything at once. This technique forces you to understand the system before touching it.

## When to use
- A problem feels overwhelming or like everything is connected to everything
- You keep solving one thing and another thing breaks
- You do not know where to start
- You want to find the highest leverage point before taking action
- A situation has too many variables to think through linearly

## How to apply

When this technique is triggered do not solve the problem. Map it.

**Step 1 — Identify all the moving parts**
List every element involved in the situation. People, processes, constraints, resources, external forces, feedback loops. Get everything on the table before analyzing any of it.

**Step 2 — Map the connections**
For each element identify what it drives and what drives it. Show the direction of influence. Some elements are causes. Some are symptoms. Most people spend all their time on symptoms.

**Step 3 — Find the leverage point**
Identify the single element that if changed would create the most ripple effects across the whole system. This is almost never the most obvious or most urgent element. It is usually upstream of everything else.

**Step 4 — Show the output clearly**
Present the map in a way the user can actually use. Name the leverage point explicitly. Explain why it drives everything else. Tell the user what to ignore for now.

## Gotchas
- Do not solve the problem after mapping it unless the user asks. The map is the output.
- Do not list everything as equally important. Force a hierarchy.
- The leverage point is singular. If you identify three leverage points you have not done the work.
- Symptoms are not leverage points. Always trace back to what is driving the symptom.

## Trigger prompt
"Do not solve this. Map it. Show me all the moving parts, how they connect, which ones drive which others, and which single lever if pulled would create the most change across the whole system."
