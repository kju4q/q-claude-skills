# Example rules file

This is the shape of a rules file the self-review skill can edit cleanly. The format
matters: each rule is one self-contained bullet with a clear claim, so Claude can edit
a single rule without disturbing the rest of the file.

Use this as a template. Replace the content with your own domain (writing style, code
review, outreach, hooks, whatever recurring task you want to keep sharp).

---

## Rules

- Open with a specific scene or number, never a generic claim. "5 projects in one weekend" beats "some project ideas."
- Keep the first line under 6 seconds spoken. The hook earns the rest of the video.
- One concrete takeaway per piece. If a viewer can't name what they learned, cut something.
- First-person framing ("the way I'd...", "I built...") outperforms instructional framing ("how to...").

## Rules added by self-review

_The self-review skill appends new evidence-backed rules here, so you can always see
which rules you wrote and which the system learned. Starts empty._
