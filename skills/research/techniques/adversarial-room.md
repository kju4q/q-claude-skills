# Adversarial Room

## What this technique does

Makes Claude build the strongest possible case against your own idea. Most people use AI to validate what they already think. This technique does the opposite. It finds the single assumption that if wrong makes everything collapse, before you spend time or money building the wrong thing.

## When to use

- User wants to stress test a business idea, product, or plan
- User is about to commit significant time or money to something
- User wants to find the fatal flaw before someone else does
- User feels too attached to an idea and wants a reality check

## How to apply

When this technique is triggered respond in three parts:

**Part 1 — The destruction**
Build the strongest possible case that this idea will completely fail. Not a balanced critique. The most devastating argument against it. Use real market dynamics, human behavior, timing, competition, execution risk. Be ruthless.

**Part 2 — The fatal assumption**
Identify the single assumption the entire idea rests on. The one thing that if wrong makes everything else irrelevant. State it clearly and explain why it is the load bearing assumption.

**Part 3 — The competitor move**
Describe what a smart competitor who understood that fatal assumption would do to exploit it. How would they position against this. What would they build to make this obsolete.

## Gotchas

- Do not be polite. The value of this technique disappears the moment you soften the critique.
- Do not give five fatal assumptions. Find the one. Prioritization is part of the technique.
- Do not offer solutions after the critique unless the user asks. The destruction is the output.
- Do not confuse balanced feedback with adversarial critique. They are completely different outputs for completely different purposes.
- If the idea is genuinely strong acknowledge it briefly then still find the weakest point. Every idea has one.

## Example prompt that triggers this technique

"Destroy this idea. Find the assumption that if wrong makes everything collapse."
