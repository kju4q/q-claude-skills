# The Model Underneath the Breakdown

## What this technique does
Finds the wrong mental model under a recurring conflict or a process that keeps failing. Not a people problem, not a communication problem, a model problem: two people built different maps of how something works and never compared them. This technique surfaces the contradiction at the foundation so you can update the model instead of managing the mood.

## When to use
- A cofounder conflict that keeps recurring
- A process that fails the same way every time
- A decision that keeps getting revisited and never settles
- Any pattern you keep solving the same way that keeps coming back

## How to apply

When this technique is triggered, work from the pattern, not a single instance. Ask the user to describe the recurring pattern, not one fight. One instance looks like a people or communication problem. The pattern reveals the model problem.

**Step 1 — surface the beliefs**
Ask: what does each person in this dynamic believe should be true about how this works? Map each person's underlying model.

**Step 2 — find the foundational contradiction**
Ask: where do those beliefs contradict each other at the foundation, not at the surface? The surface is the argument. The foundation is the root assumption each person never questioned.

When the foundational contradiction is named, the recurring conflict can actually be solved, because you are reconciling the maps, not negotiating the symptom.

This works on solo patterns too. If the user keeps revisiting the same decision, run it on the contradicting beliefs inside their own head.

## Gotchas
- Work from the pattern, not one instance. A single fight hides the model
- Surface contradictions are a trap. Push to the foundational assumption underneath
- Do not turn this into conflict mediation. The goal is updating the model, not smoothing the feelings
- The real contradiction is usually something both people assumed and never said

## Trigger prompt
"Here is a pattern that keeps repeating: [pattern, not one instance]. What does each person in this dynamic believe should be true about how this works? Then: where do those beliefs contradict each other at the foundation, not at the surface?"
