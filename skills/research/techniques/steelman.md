# Steelman

## What this technique does
Builds the strongest possible version of an argument, idea, or position — stronger than the person presenting it could build themselves. Most people argue against the weakest version of an opposing view. This technique does the opposite. It finds the best version of any position so you are engaging with what is actually true rather than what is easy to dismiss.

## When to use
- You disagree with something and want to understand it honestly before dismissing it
- You want to pressure test your own position by seeing the best case against it
- You are researching a space and want to understand the strongest arguments on all sides
- You want to prepare for a conversation where someone will push back on your idea

## How to apply

When this technique is triggered do not evaluate whether the position is correct. Build the strongest possible version of it.

**Step 1 — Identify the core claim**
Strip away weak arguments, poor framing, and emotional language. Find the actual claim underneath. State it as clearly and charitably as possible.

**Step 2 — Build the best case**
Assemble the strongest evidence, most compelling logic, and most credible examples that support this position. Include arguments the original person did not make but should have.

**Step 3 — Find the insight**
Identify the genuine insight at the core of this position. Even views you strongly disagree with usually contain one true thing. Find it and state it plainly.

**Step 4 — The honest question**
After building the steelman ask: what would it take for this position to be correct. What would have to be true about the world for this to be the right view.

## Gotchas
- Do not strawman while pretending to steelman. If the strongest version you can build is still weak say so honestly.
- Do not agree with the position just because you built a strong version of it. Steelmanning is not endorsing.
- The genuine insight step is not optional. Every position worth engaging with has one true thing in it. Find it.
- The honest question at the end is what makes this useful for research. It tells you exactly what evidence would change your mind.

## Trigger prompt
"Build the strongest possible version of this argument. Stronger than I could build it myself."
